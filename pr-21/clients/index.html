Feature definitions

Replica reads
Route read commands to replicas instead of the primary, spreading read load across the topology.
Pub/Sub
Re-subscribe to channels and patterns automatically after a reconnect or topology change, so subscribers never go silently deaf.
SCAN family
Iterate keys consistently across every shard, tracking slot migrations that happen mid-scan.
AZ affinity
Prefer replicas in the client’s own availability zone to cut cross-AZ latency and transfer cost.
Client-side caching
Keep hot values in the application process and let the server invalidate them, removing a round trip entirely.
Advanced capabilities
Announce client capabilities so the server can hand off slot redirections cleanly during upgrades and failover.
Connection pooling
Reuse a pool of established connections rather than dialing one per command.
