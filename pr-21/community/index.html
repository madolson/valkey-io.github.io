Ways to contribute

Pick the path that matches how you want to help.

Contribute to Core

Help build the Valkey engine itself. Browse open issues, read the contributing guide, and submit a pull request to the core repository.

GitHub Repository Contributing Guide

Contribute to Modules

Extend Valkey's capabilities by contributing to modules such as Valkey Search, Valkey Bloom, Valkey JSON, or the Rust module SDK (valkeymodule-rs).

Valkey Modules on GitHub

Submit a Bug / Security Vulnerability

If you encounter an issue while using Valkey, please help us improve the project by filing a bug report. For potential security issues, please follow our security policy instead of opening a public issue.

Report a Bug Security Policy

Contribute to Documentation

Help make Valkey easier to learn and use. Documentation content, tutorials, and topic guides live in the valkey-doc repository and welcome pull requests.

valkey-doc Repository

Feature Requests

We value your ideas! If you have a suggestion for a new feature, submit a feature request on GitHub and help shape the roadmap.

Submit a Feature Request

Content: Blogs / Videos

Share your Valkey story. Write a blog post, record a demo, or contribute a tutorial video to help others learn from your experience.

Blog Guidelines Video Guidelines
