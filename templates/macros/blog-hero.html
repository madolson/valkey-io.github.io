{%- endcomponent blog_hero.card %} {# The card's text layout. The browser cannot be told "wrap, but never leave one word on the last line, and never use more than two lines", so the template sets the lines and the browser draws them unwrapped. Widths come from Open Sans's advance widths in _data/blog-hero/open-sans-400.json, written by build/blog-hero.py; without kerning, the sum runs up to about 2% wider than the browser draws, so lines come out a little short of their limits, never over them. All lengths are in cqi of a card 56.25cqi tall, so a layout holds at every card width. Each line has two limits, read at its bottom edge: a soft one, where text wraps by default, and a hard one it may run to when that avoids a third line or a one-word last line. Both stay off the wave in the background: the soft one left of its dust, the hard one left of its bright core. The tables give the right edge (% of width) allowed below each height (% of height), measured from default-bg.webp. #} {# Each word's width in em, "|"-separated, then the whole text's width last. #} {% component blog_hero.widths(text) -%} {%- set glyphs = load_data(path="_data/blog-hero/open-sans-400.json") -%} {%- set out = "" -%} {%- set total = 0 -%} {%- set words = 0 -%} {%- set w = 0 -%} {%- for word in text | split(pat=" ") %}{% if word %} {%- set_global w = 0 -%} {%- for c in word | split(pat="") %}{% if c %}{% set_global w = w + glyphs[c] | default(value=0.6) %}{% endif %}{% endfor -%} {%- set_global out = out ~ w ~ "|" -%} {%- set_global total = total + w + (glyphs[" "] if words else 0) -%} {%- set_global words = words + 1 -%} {%- endif %}{% endfor -%} {{ out }}{{ total }} {%- endcomponent blog_hero.widths %} {# The right edge, % of the card's width, the wave allows at a height, % of its height. #} {% component blog_hero.edge(y, edge) -%} {%- if edge == "dust" -%} {%- set table = [[32, 63], [38, 58], [45, 55], [50, 49], [54, 48], [60, 40], [101, 38]] -%} {%- else -%} {%- set table = [[22, 85], [26, 82], [30, 78], [34, 74], [38, 69], [42, 64], [46, 59], [50, 54], [54, 51], [58, 48], [62, 45], [101, 44]] -%} {%- endif -%} {%- set x = 0 -%} {%- for row in table %}{% if x == 0 and y < row | first %}{% set_global x = row | last %}{% endif %}{% endfor -%} {{ x }} {%- endcomponent blog_hero.edge %} {# The widths, in em at size f, of the lines with first baseline `base`, each read at the line's bottom edge: "soft1|hard1|hard2". One line whenever the text fits the hard limit.
